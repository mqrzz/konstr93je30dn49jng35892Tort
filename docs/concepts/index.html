Core concepts

The handful of ideas that explain everything else in Geserd: domains, keys, emails, events and limits.

Domains

A domain is the address you send from, such as mail.yourshop.com. Geserd generates a DKIM key pair for it and shows the DNS records that prove you control it. Until the records are verified, the domain is in the sandbox and can send only to your own account address.

API keys

A key lets your code talk to the API. It is shown once, stored only as a hash, and can be revoked at any time. Create separate keys for separate apps so that revoking one never breaks the others.

Emails and their life

Sending returns an id immediately and the message is queued. It then moves through states: sent, delivered, or bounced and complained when something goes wrong. Every step is written to the event log and, if you set up a webhook, pushed to your server.

Events, webhooks and limits

  • Events describe what happened to a message, for example email.delivered.
  • Webhooks deliver events to your server, signed so you can trust them.
  • Limits cap sending per day and per month on every plan.
