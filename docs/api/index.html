API reference

Every endpoint, its fields, and the shape of its response.

Geserd is in active development. Domains endpoints below are live today. Sending and receiving are designed but not live yet — track progress on the changelog.

Domains

Add, list, inspect and verify the domains you send and receive from.

LivePOST /api/domains
namerequiredstring

mail.yourdomain.com

LiveGET /api/domains/:id

LiveDELETE /api/domains/:id

Send email

Designed — not live yetPOST /api/emails

POST /api/emails. Requires a from address on a verified domain, one or more recipients, a subject, and an html or text body.

fromrequiredstring
torequiredstring | array
subjectrequiredstring
htmloptionalstring
textoptionalstring
reply_tooptionalstring
in_reply_tooptionalstring

Receiving

Designed — not live yetemail.received

Mail sent to a verified domain is delivered to your webhook as an email.received event. Reply by sending a new email with in_reply_to set to the received message's id.
