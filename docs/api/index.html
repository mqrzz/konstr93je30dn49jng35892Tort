API reference

Every endpoint, its fields, and the shape of its response.

Send email

POST /api/emails. Requires a from address on a verified domain, one or more recipients, a subject, and an html or text body.

Fields
from          string, required
to            string or array, required
subject       string, required
html          string
text          string
reply_to      string
in_reply_to   string (id of a received message)
Response
202 { "id": "8f2c1e0a-4b7d", "status": "queued" }

Domains

POST /api/domains adds a domain and generates its DKIM key pair. GET /api/domains/:id returns its status and DNS records. POST /api/domains/:id/verify checks DNS and updates the status.

Receiving

Mail sent to a verified domain is delivered to your webhook as an email.received event. Reply by sending a new email with in_reply_to set to the received message's id.

email.received
{ "type": "email.received",
  "data": { "id": "...", "from": "a@b.com", "to": ["hi@yourdomain.com"],
            "subject": "Re: Hello", "text": "...", "html": "..." } }
