Get started

Introduction

Geserd is an email API for developers.

To get started with Geserd, you'll need:

  1. Your own domain, verified with Geserd
  2. A Geserd API key

Then, you'll be ready to send and receive email through the API:

  • Sending: personalized, event-driven transactional email from your verified domain
  • Receiving: inbound mail delivered to your webhook, with replies sent from the same address
