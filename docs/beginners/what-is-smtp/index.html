What is SMTP

SMTP is the language mail servers use to hand messages to each other. You will meet the word often, so it helps to know what it means.

A postal system for the internet

Think of SMTP as the rules of the postal service. When you post a letter, you write the address on the envelope, drop it at a post office, and the post office passes it from sorting centre to sorting centre until it reaches the right door. SMTP does the same for email: the sending server writes who the message is from and who it is for, then passes it on until the receiving server accepts it.

Why you might need it

Many programs that send email, such as online shop engines, website builders and newsletter tools, have a settings page that asks for an SMTP server, a port, a username and a password. That page is simply asking where to hand the message. Geserd gives you those four values, so the program can use us without any code.

The four values

SMTP
server:   smtp.geserd.com
port:     465 (encrypted from the start) or 587
username: geserd
password: your API key
  • Server: the address of the post office. For Geserd it is smtp.geserd.com.
  • Port: which door to use. Use 465 if the program offers “SSL” or “TLS”, and 587 if it offers “STARTTLS”. When in doubt, try 465 first.
  • Username and password: the username is a fixed word and the password is an API key that you create in the dashboard. Treat it like a password: anyone who has it can send mail as you.

The server name and the exact values for your account are also shown in the dashboard under SMTP, ready to copy.
