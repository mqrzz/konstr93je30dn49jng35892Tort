What is SMTP

SMTP is how one mail server hands a message to another.

The post office model

Think of your app dropping a letter at a post office. The post office checks the address, then passes the letter on until it reaches the recipient’s mailbox. SMTP is the set of rules for that handover.

Two ways to send

With Geserd you can call the HTTP API, or connect any app that speaks SMTP using your API key as the password. Both end up in the same logs.

Ports 465 and 587

Port 465 starts encrypted from the first byte. Port 587 starts plain and upgrades to encryption with STARTTLS. Either is fine; pick the one your app supports.
