You do not need to be a developer to use Geserd. This section explains email in plain words and walks you through setting it up.

What Geserd does for you

When your website or shop needs to email a customer, for example a receipt, a login code or a password reset, something has to deliver that message. Geserd is that something. You tell it which address the message comes from, it signs the message so other servers trust it, delivers it, and keeps a log of what happened.

The path in five steps

  • Create an account and add your domain. Use the address you already have, such as yourshop.com, or a subdomain like mail.yourshop.com.
  • Copy the DNS records. Geserd shows a short list of records. They prove that the domain is yours and allow us to send for it.
  • Paste them where you bought the domain. Every domain company has a DNS page. The next guides show how.
  • Press verify. Geserd checks the records and turns the domain green when everything is in place.
  • Send your first email. From the dashboard or through a tool that connects to us with an API key or SMTP.
