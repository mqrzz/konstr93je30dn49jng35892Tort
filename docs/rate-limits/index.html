Rate limits

How sending and receiving limits work, and what happens when you hit one.

Two limits per plan

Every plan has a monthly send limit and a daily send limit, plus a separate monthly inbound limit. Hitting the daily limit only blocks sending until the next day; hitting the monthly limit blocks sending until the plan resets or you upgrade. See the pricing page for the exact numbers per plan.

Response when limited

429
{ "error": "plan_limit" }

A send request that would exceed a limit is rejected before it is queued, so it never appears in your logs as attempted. Check the Usage page in Settings to see how close you are to each limit.

API request rate

Independently of send limits, the API also limits how many requests per second a single API key can make, to protect the platform from accidental request loops. This limit is generous for normal use and only matters if a bug in your integration is retrying in a tight loop.
