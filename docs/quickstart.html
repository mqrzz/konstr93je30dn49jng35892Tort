Быстрый старт

От пустого аккаунта до отвечающего бота — пять шагов, без строчки кода.

1. Создайте бота через BotFather

Откройте @BotFather в Telegram, отправьте команду /newbot и следуйте инструкциям. В конце BotFather выдаст токен вида:

847291:AAH4d9x2K...опущено
Никому не показывайте токен — он даёт полный доступ к боту. Flowgram хранит его в зашифрованном виде.

2. Подключите бота в Flowgram

В кабинете нажмите Создать бота, вставьте токен из BotFather. Flowgram проверит его через Telegram API и автоматически зарегистрирует вебхук — вручную ничего настраивать не нужно.

3. Соберите первый сценарий

Откройте конструктор и начните с триггера /start. Добавьте ноду Сообщение с приветственным текстом, затем — ноду Кнопки с двумя-тремя вариантами продолжения диалога.

  • Перетащите блок из левой панели на канвас
  • Соедините его с предыдущей нодой, потянув от точки на нижней грани
  • Кликните по ноде, чтобы отредактировать текст справа

4. Проверьте в песочнице

Нажмите Тест в верхней панели конструктора и отправьте /start тестовому боту — сценарий выполнится без публикации, изменения не увидят реальные пользователи.

5. Опубликуйте

Кнопка Опубликовать сохраняет текущий сценарий отдельной версией и выкатывает его на живого бота. Если что-то пойдёт не так — вернуться к предыдущей версии можно в один клик на вкладке Версии.
