API reference

Emails

Send a message, check it before sending, and read its status.

Send

POST /api/emails queues a message and answers 202 with its id. The from address must be on a verified domain.

FieldDescription
fromSender, on a verified domain. Required.
toOne address or a list. Required.
subjectSubject line. Required.
htmlHTML body. Send html, text or both.
textPlain-text body. Recommended next to html.
reply_toWhere replies should go.
in_reply_toId of a received message, to answer it in the same thread.
attachmentsFiles to attach, as a list.

Check before sending

POST /api/emails/check accepts the same body and returns the spam score and the rules that fired, without sending anything or using your limits.

Read

GET /api/emails lists recent messages and GET /api/emails/:id returns one message with its status and events.
