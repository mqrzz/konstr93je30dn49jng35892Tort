Send with Node.js

Send your first email from Node.js 18 or newer with the built-in `fetch`. No library is required.

Send a message

send.js
const res = await fetch("https://geserd.com/api/emails", {
  method: "POST",
  headers: {
    "Authorization": "Bearer " + process.env.GESERD_KEY,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    from: "Shop <orders@mail.yourshop.com>",
    to: ["client@example.com"],
    subject: "Your order",
    html: "<p>Thank you!</p>",
    text: "Thank you!"
  })
});
const data = await res.json();
if (!res.ok) throw new Error(data.error);
console.log(data.id);

Keep the key in an environment variable named GESERD_KEY. The response contains the message id, which you can look up in the Logs page or through GET /api/emails/:id.

Handle errors and retries

Retry only on 429 and 5xx, with a growing pause. A 4xx other than 429 means the request itself must change, so repeating it will not help. Use an idempotency key if a retry could otherwise send the same message twice.
