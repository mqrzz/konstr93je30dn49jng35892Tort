Errors

How geserd reports problems, and what each error means.

Error format

Every error response is JSON with an error field identifying the problem, and the HTTP status code reflects the category of failure: 4xx for something wrong with the request, 5xx for a problem on our side.

Error response
{ "error": "invalid_domain" }

Common codes

HTTPerrorMeaning
401unauthorizedMissing or invalid API key
403plan_limitThe action would exceed your plan's limit, for example the number of domains
404not_foundThe resource does not exist or does not belong to your account
409existsA resource with this value already exists, for example a duplicate domain
422invalid_domainThe domain name is not a valid, syntactically correct domain
429rate_limitedToo many requests in a short time; slow down and retry
500server_errorSomething failed on our side; safe to retry

Retrying

For 429 and 5xx responses, wait and retry with backoff. For 4xx responses other than 429, fix the request before retrying, since repeating the same invalid request will just fail again.
