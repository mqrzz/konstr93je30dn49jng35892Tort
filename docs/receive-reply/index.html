Receive and reply

Receive mail sent to your domain and answer it from the same address.

Point the domain at Geserd

Add the MX record shown for your domain at your DNS provider. If the domain already receives mail somewhere else, use a subdomain such as inbox.yourshop.com so the two never compete.

Handle the event

email.received
{ "type": "email.received",
  "data": { "id": "...", "from": "client@example.com",
            "to": ["support@inbox.yourshop.com"],
            "subject": "Question", "text": "...", "html": "..." } }

Answer

Reply by sending a normal email with in_reply_to set to the id of the received message. Geserd adds the threading headers, so the answer appears in the same conversation in the customer’s mailbox.
