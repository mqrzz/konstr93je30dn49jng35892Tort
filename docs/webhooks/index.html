Verifying the signature

Each request carries three headers: Geserd-Id, Geserd-Timestamp and Geserd-Signature. The signature is v1= followed by the hex HMAC-SHA256 of id.timestamp.body using your webhook secret. Compare it in constant time and reject requests whose timestamp is more than five minutes old.

verify.js
const crypto = require("crypto");
function ok(secret, h, raw) {
  const sig = "v1=" + crypto.createHmac("sha256", secret)
    .update(h["geserd-id"] + "." + h["geserd-timestamp"] + "." + raw)
    .digest("hex");
  const a = Buffer.from(sig), b = Buffer.from(h["geserd-signature"] || "");
  const fresh = Math.abs(Date.now() / 1000 - Number(h["geserd-timestamp"])) < 300;
  return fresh && a.length === b.length && crypto.timingSafeEqual(a, b);
}

Delivery and retries

Answer with any 2xx status within ten seconds. Other answers are retried with growing pauses. Webhook addresses that resolve to private networks are refused, so use a public HTTPS address.
