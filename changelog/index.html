Changelog

What changed in Geserd, newest first.

Authentication, service settings and a better editor

  • Authentication module: send and check email one-time codes with two API calls
  • Service settings: sender defaults, spam protection level, suppression switches, allowed IP addresses
  • Account settings moved to their own page with sign-in methods and a data export
  • New mobile top bar and menu, a real settings icon, calmer notifications
  • Templates: search, sorting, undo and redo, drag and drop, list, quote and links blocks, preview text, version history, usage counts
  • Notifications: filters and delete read

Templates and the email editor

  • Templates and a visual email editor with live preview and variables
  • Send with template_id and variables through the API
  • Send a test email from the editor
  • API reference brought up to date

SMTP, spam score, support and status

  • SMTP sending on ports 465 and 587 with an API key as the password
  • Spam score for every outgoing email and a check endpoint before sending
  • Support tickets inside the dashboard and a live status page with 90-day history
  • Notifications for bounces, complaints, limits, domains and support replies
  • Account settings, sessions and per-type email alerts
