Вебхуки

Получайте события бота на свой сервер в реальном времени — без опроса API.

Регистрация вебхука

Укажите URL и список событий, на которые хотите подписаться:

POST /bots/847291/webhook { "url": "https://ваш-сервер.ру/hooks/flowgram", "events": ["message.received", "button.clicked", "payment.completed"] }

Типы событий

СобытиеКогда срабатывает
message.receivedПользователь написал боту
button.clickedНажата кнопка в сценарии
payment.completedОплата прошла успешно
user.blockedПользователь заблокировал бота

Проверка подписи

Каждый запрос вебхука подписывается HMAC-SHA256 в заголовке X-Flowgram-Signature. Сверяйте подпись на своей стороне, чтобы убедиться, что запрос действительно пришёл от Flowgram, а не от третьей стороны.

Если ваш сервер не отвечает 200 OK в течение 5 секунд, Flowgram повторит доставку ещё дважды с интервалом в минуту.

Пример обработчика на Express

app.post('/hooks/flowgram', (req, res) => { const valid = verifySignature(req); if (!valid) return res.sendStatus(401); if (req.body.type === 'payment.completed') { markOrderPaid(req.body.data.chat_id); } res.sendStatus(200); // отвечайте сразу, обработку делайте асинхронно });

Политика повторов

ПопыткаКогда
1-яСразу при наступлении события
2-яЧерез 1 минуту, если сервер не ответил 200 OK
3-яЧерез 5 минут после второй попытки

После трёх неудачных попыток событие помечается как недоставленное и видно в логе вебхука в кабинете бота.
