Документация / API

API

Управляйте ботом из своего кода там, где визуального конструктора недостаточно.

Аутентификация

Все запросы подписываются ключом API из настроек бота, который передаётся в заголовке:

Authorization: Bearer fg_xxxxxxxxx
Ключ доступен только на тарифах Pro и выше — на Free и Start API-доступ выключен.

Messages API

Отправка сообщения от имени бота напрямую, в обход сценария — например, для уведомления о статусе заказа из вашей CRM:

POST /messages { "bot_id": "847291", "chat_id": "193004521", "text": "Заказ №1042 передан курьеру" }

Rate limits

Ограничения зависят от тарифа бота, а не от аккаунта в целом:

ТарифЗапросов в минуту
Pro60
Business300
Enterpriseпо договорённости

При превышении лимита API возвращает 429 Too Many Requests с заголовком Retry-After.
