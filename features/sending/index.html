The careful parts are done
Your domain, your signature
Every message carries a DKIM signature for your domain, so receivers see mail from you, not from a shared sender.
DKIM-Signature: v=1; a=rsa-sha256;
 d=yourdomain.com; s=geserd;
 h=from:to:subject:date; b=Zk3q…

Connect the way you prefer
New code can call the HTTP API. Existing software that only knows SMTP just needs a host and your API key as the password.
curl https://geserd.com/api/emails \
  -H "Authorization: Bearer gs_live_…" \
  -d '{"from": "hi@yourdomain.com",
       "to": "ada@example.com",
       "subject": "Welcome",
       "text": "Glad you are here."}'

Questions about sending
Do I need to verify my domain first?
Yes. You can only send from addresses on a verified domain, which is what lets us sign your mail with your own DKIM key.
What happens when an address bounces?
You get a bounce event with the reason. Depending on your settings, the address is added to your suppression list and skipped from then on.
How do I connect software that only supports SMTP?
Use smtp.geserd.com on port 465 or 587, any username, and your API key as the password.
