Setup

Three steps, no install

  1. 1Add the server

    One click with Add to Cursor, or edit .cursor/mcp.json yourself.

  2. 2Paste your key

    Create an API key in the dashboard and put it in the Authorization header.

  3. 3Ask the agent

    The five Geserd tools show up in the agent’s tool list. Mention an email and it uses them.

Tools

What the agent can reach

Five tools, all scoped to the account that owns the key.

send_emailSend an email from a verified domain of this account.Sends
list_emailsList recent emails, newest first.Reads
get_emailRead one email together with its delivery events.Reads
list_domainsList sending domains and their verification status.Reads
