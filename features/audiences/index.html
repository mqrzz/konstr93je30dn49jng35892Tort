Import

Your columns, understood

The header row is read for you. Email is required. first_name or name and last_name fill the contact. Every other column becomes a property you can use as a template variable.

Through the API, values go in props for properties you defined first. Up to 5,000 rows per request, and you can export the whole audience to CSV at any time.

POST /api/audiences/<audience_id>/contacts

{
  "email": "ada@example.com",
  "first_name": "Ada",
  "last_name": "Lovelace",
  "props": { "plan": "Pro", "city": "London" }
}

Contacts, properties, segments, topics

Questions

Can I add contacts from my app?

Yes. Post each contact to your audience with the API, with any properties you need.

Can I delete an audience that I am sending to?

Not while a broadcast to it is scheduled, sending or paused. Finish or cancel the broadcast first.

Where do people manage topics?

On the same personal page as the unsubscribe link, where they can pick the topics they want to hear about.
