Questions

Which transport does the server use?

Plain HTTP with JSON-RPC 2.0. Send a POST to the endpoint with your key in the Authorization header.

Where do I get a key?

In the dashboard under API keys. Give each assistant its own key so you can revoke it alone.

Can an assistant delete my emails or domains?

No. The server offers only the five tools above: send, list and read.
