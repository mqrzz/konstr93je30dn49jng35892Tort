Tools

Every tool your agent needs

Five tools, each doing one thing.

send_email

Send mail from a verified domain.

list_emails

Lists recent messages.

get_email

Reads one email with its events.

list_domains

Shows domains and their status.

list_templates

Shows saved templates.

Claude Code

One command

Run it once. Then ask Claude to list your domains or send a message.

claude mcp add --transport http geserd https://geserd.com/api/mcp \
  --header "Authorization: Bearer gs_live_..."
Cursor

A short config file

Save it as .cursor/mcp.json in your project, or in your home folder to use it everywhere.

{
  "mcpServers": {
    "geserd": {
      "url": "https://geserd.com/api/mcp",
      "headers": { "Authorization": "Bearer gs_live_..." }
    }
  }
}

Questions about MCP

Does it work with the Claude app on the web?

Not yet. Custom connectors there sign in with OAuth, which Geserd does not offer. Use Claude Code or another client that sends a header.

Which key should I use?

Create a separate key for the assistant, so you can revoke it without touching your apps.
