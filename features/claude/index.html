Claude

  https://geserd.com/api/mcp \
  --header "Authorization: Bearer gs_live_..."

Manual setup

Add it to .mcp.json

Prefer a file? Add the server to your configuration yourself.

config
{
  "mcpServers": {
    "geserd": {
      "type": "http",
      "url": "https://geserd.com/api/mcp",
      "headers": { "Authorization": "Bearer gs_live_..." }
    }
  }
}
