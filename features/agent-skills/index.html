SKILL.md
1---
2name: geserd
3description: Send and read email through the user's Geserd account. Use when the user asks to send an email, check delivery of a message, list domains or work with email templates on Geserd.
4---
5 
6# Geserd
7 
8Geserd sends and receives email from the user's own domain. Authenticate every request with the API key in `GESERD_API_KEY` (it starts with `gs_`). Never print the key.
9 
10## Send an email
11 
12```bash
13curl https://geserd.com/api/emails \
14 -H "Authorization: Bearer $GESERD_API_KEY" \
15 -H "Idempotency-Key: <unique value for this message>" \
16 -d '{"from":"hi@yourdomain.com","to":["ada@example.com"],"subject":"Hello","text":"Hi Ada"}'
17```
18 
19- The sender must be on a verified domain. If the response is `domain_not_verified`, tell the user to finish DNS verification in the dashboard.
20- Reuse the same `Idempotency-Key` when retrying so the message is sent once.
21 
22## Check what happened
23 
24- `GET /api/emails?limit=20` lists recent messages.
25- `GET /api/emails/{id}` returns the message and its events (sent, delivered, bounced, complained).
26 
27## Rules
28 
29- Ask the user to confirm the recipients and the text before sending anything.
30- Only write to people who agreed to hear from the user. Do not send bulk mail from here, use Broadcasts for that.
31- If the MCP server is connected (`https://geserd.com/api/mcp`), prefer its tools `send_email`, `list_emails`, `get_email`, `list_domains` and `list_templates`.

Questions

What is an agent skill?

A short instruction file the agent reads when a task matches. It teaches a routine, it does not run code.

Skill or MCP server?

The skill teaches the rules, the MCP server gives the tools. If both are present, the skill tells the agent to prefer the MCP tools.

Does it need an API key?

Yes. The agent reads it from the GESERD_API_KEY variable and never prints it.

Can the agent send bulk mail with it?

No. The file tells the agent to ask for confirmation first and to use Broadcasts for bulk mail.
