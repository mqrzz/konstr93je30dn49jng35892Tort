Templates

Design once, send with variables

Save a message as a template. Your code sends only the template id and the values to fill in, and the editor shows exactly what the recipient will see.

In your code

Send by template id

Variables are written as double braces in the template, for example the name placeholder, and replaced for each message.

curl https://geserd.com/api/emails \
  -H "Authorization: Bearer gs_live_..." \
  -d '{"from": "hi@yourdomain.com",
       "to": "ada@example.com",
       "template": "welcome",
       "variables": {"name": "Ada"}}'
The editor

What you can do

Blocks or HTML

Switch between the block editor and raw HTML. Both give the same email.

Desktop and phone preview

Check both widths before you save, in light and dark.

Version history

Every save keeps a version, and you can restore an earlier one.

Test email

Send the template to yourself with sample values before it goes live.

Questions about templates

What happens to old emails if I edit a template?

Emails already sent are not affected. Only new messages use the new version.
