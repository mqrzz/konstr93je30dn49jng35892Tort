Simple sending

Simplify your email sending

Send only the template id and the variables. The design lives in the editor, not in your code.

Node.js
await fetch("https://geserd.com/api/emails", {
  method: "POST",
  headers: { Authorization: "Bearer gs_live_..." },
  body: JSON.stringify({
    from: "hi@yourdomain.com",
    to: "ada@example.com",
    template_id: "<id>",
    variables: { name: "Ada" }
  })
});
