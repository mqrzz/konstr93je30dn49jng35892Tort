Questions
Can I use a template in a broadcast?
Yes. Pick it when you write the broadcast, and variables are filled for each contact.
Is the HTML in a variable escaped?
Yes. Special characters are escaped in the HTML part, so a value cannot add tags to your message.
Can I send a test?
Yes. Send a test to your own address from the editor, with the sample values you set.
