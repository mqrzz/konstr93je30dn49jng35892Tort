Automation

Ready for CI/CD environments

Set GESERD_API_KEY as a variable and send from any pipeline, with no login step.

CI
env:
  GESERD_API_KEY: ${{ secrets.GESERD }}
run: |
  node geserd.mjs send \
    --from ci@yourdomain.com \
    --to team@yourdomain.com \
    --subject "Deploy done" --text ok
