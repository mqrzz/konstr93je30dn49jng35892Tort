Send email from your terminal

One file, five commands. Send a message, list what you sent and read any email, with no install step.

Download geserd.mjsDocumentation

Needs Node.js 18 or newer and your API key in GESERD_API_KEY.

Commands

Five commands, nothing hidden

Pick a command to see what it takes and what it prints.

Sends an email. Repeat --to for several recipients. Prints the API response as JSON.

geserd send --from hi@yourdomain.com --to ada@example.com \
  --subject "Hello" --text "Hi Ada"

Flags

  • --fromstringrequired
  • --tostringrequired
  • --subjectstringrequired
  • --textstring
  • --htmlstring

Lists recent emails as a table with id, status and subject.

geserd emails --limit 20

Flags

  • --directionin | out
  • --limit20

Example output

9efc…   delivered   Welcome to Acme
41ab…   bounced     October newsletter
c07d…   delivered   Your receipt

Prints one email with its events as JSON.

geserd email 9efc…

Flags

  • stringrequired

Lists your domains and their verification status.

geserd domains

Flags

  • No flags

Example output

acme.dev   verified
news.acme.dev   pending

Lists your saved templates.

geserd templates

Flags

  • No flags

Example output

c325…   Welcome email   Welcome to Acme
9e23…   Invoice   Your invoice
Output

Made for eyes and for scripts

$ geserd emails
9efc…   delivered   Welcome to Acme
41ab…   bounced     October newsletter
A table to read

emails, domains and templates print aligned columns you can scan at a glance.

$ geserd email 9efc… | jq .status
"delivered"
JSON to pipe

send and email print the full API response, ready for jq or a script.

In your pipeline

No login step

Put the key in a secret, expose it as GESERD_API_KEY and send from any CI job. Set GESERD_URL only if you use another address.

jobs:
  notify:
    runs-on: ubuntu-latest
    steps:
      - run: |
          node geserd.mjs send \
            --from ci@yourdomain.com \
            --to team@yourdomain.com \
            --subject "Deploy done" --text ok
        env:
          GESERD_API_KEY: ${{ secrets.GESERD }}

Questions

Do I need to install it?

No. It is one file. Download it and run it with node.

Where do I get the API key?

In the dashboard under API keys. It starts with gs_.

What happens if a command fails?

It prints the error to stderr and exits with code 1, so a CI job fails as it should.
