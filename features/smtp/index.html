SMTP

Plain SMTP, your own domain

If your software only knows SMTP, point it at Geserd. The same signing, queue and log apply as for the API.

Settings

Connection details

Hostsmtp.geserd.com
Port465 with SSL, or 587 with STARTTLS
UsernameAny value
PasswordYour API key, which starts with gs_
Message sizeUp to 10 MB
Connecting

Three minutes

  1. 01

    Verify a domain

    Add the DNS records shown in your dashboard. Mail can only be sent from verified addresses.

  2. 02

    Create an API key

    The key is shown once. Use it as the SMTP password.

  3. 03

    Enter the settings

    Paste the host and port into your software and send a test message.

Questions about SMTP

Is the connection encrypted?

Yes. Use port 465 for SSL or 587 for STARTTLS.
