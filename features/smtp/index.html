Port 465 is shown. For 587, use STARTTLS instead of SSL in the same place.

import nodemailer from "nodemailer";

const transport = nodemailer.createTransport({
  host: "smtp.geserd.com",
  port: 465,
  secure: true,
  auth: { user: "geserd", pass: process.env.GESERD_API_KEY }
});

await transport.sendMail({
  from: "hello@acme.dev",
  to: "ada@example.com",
  subject: "Welcome to Acme",
  text: "It works."
});
import os, smtplib

msg = EmailMessage()
msg["From"] = "hello@acme.dev"
msg["To"] = "ada@example.com"

What the server does

One pipeline, two doors

A message sent over SMTP is treated exactly like an API call.

  1. 1
    Authenticate

    The password must be an active API key starting with gs_. Wrong credentials get a 535 reply.

  2. 2
    Check

    Your account’s allowed addresses and plan limits apply, and the From domain must be verified.

  3. 3
    Send and log

    The message is signed, queued and sent. Its request shows up in Logs next to your API calls.

Questions

What is the user name?

Use geserd. Only the password matters, and it must be an API key.

Does it receive mail too?

This port is for sending. To receive mail, point your MX record at Geserd and read messages in Emails or by webhook.

Is the connection encrypted?

Always. Port 465 is encrypted from the start and port 587 must upgrade with STARTTLS before you can log in.
