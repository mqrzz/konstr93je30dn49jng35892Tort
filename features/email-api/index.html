Node.js
await fetch("https://geserd.com/api/emails", {
  method: "POST",
  headers: { Authorization: "Bearer gs_live_..." },
  body: JSON.stringify({
    from: "hi@yourdomain.com",
    to: "ada@example.com",
    subject: "Welcome",
    html: "<p>Glad you are here.</p>"
  })
});
Safe retries

Idempotency keys

Send the same key twice and the email goes out once, so a retry never duplicates a message.

curl
curl https://geserd.com/api/emails \
  -H "Authorization: Bearer gs_live_..." \
  -H "Idempotency-Key: order-1042" \
  -d '{"from":"hi@yourdomain.com",...}'
