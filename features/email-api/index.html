Email API

One call, one email

A small HTTP API for sending and receiving. Authenticate with a key, send JSON and get an id back right away.

Send

This is the whole request

curl https://geserd.com/api/emails \
  -H "Authorization: Bearer gs_live_..." \
  -H "Idempotency-Key: order-1042" \
  -d '{"from": "hi@yourdomain.com",
       "to": "ada@example.com",
       "subject": "Welcome",
       "text": "Glad you are here."}'
Details that matter

Made to be safe in production

Idempotency

Send the same key twice and the email goes out once, so retries are safe.

Clear errors

Every error has a code and a message that says what to change.

Rate limits

Limits are documented, and responses tell you when to try again.

Webhooks

Delivery, bounce and inbound events are posted to your URL.

Questions about the API

Which languages can I use?

Any language that can make an HTTP request. The documentation has examples for Node.js, Python and PHP.
