Отправить первое сообщение

После публикации бота можно управлять им и из своего кода — например, слать уведомления о заказе в обход конструктора.

quickstart.js
import { Flowgram } from 'flowgram'; const flowgram = new Flowgram('fg_xxxxxxxxx'); await flowgram.messages.send({ bot_id: '847291', chat_id: '193004521', text: 'Заказ №1042 передан курьеру 🚚' });

Справочник блоков сценария

Основные типы нод, доступные в конструкторе прямо сейчас.

message
Сообщение

Отправляет текст, фото или файл. Поддерживает переменные вида {{name}}.

buttons
Кнопки

Показывает inline- или reply-кнопки и ведёт к следующей ноде по выбору.

condition
Условие

Ветвит сценарий по значению переменной, времени или сегменту пользователя.

payment
Оплата

Выставляет счёт через ЮKassa и ждёт подтверждения перед следующим шагом.

delay
Задержка

Приостанавливает сценарий на заданное время перед следующим действием.

http
HTTP-запрос

Вызывает внешний API или свой JS-обработчик, результат кладёт в переменную.
